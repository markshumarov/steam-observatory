Издания Теги Демо Методология

Участники по изданиям

Синие столбцы — финальный состав, серая линия с точками — зарегистрировавшиеся (press preview, где архив сохранил), красные точки — контрольные данные GameDiscoverCo. Издания с расхождением с контролем больше 25% не публикуются.

Насыщенность тегов

Клик по тегу добавляет или убирает его. Доля считается среди участников издания, поэтому рост поля не искажает картину.

Игроки в демо: октябрь 2026

Пик одновременных игроков по каждому демо. Сбор идёт непрерывно до конца фестиваля (26 октября, 17:00 UTC), поэтому цифры растут.

Методология

Состав изданий: публичный эндпоинт страницы фестиваля и архивные копии Internet Archive. Игроки: публичный API Steam. Контроль качества: число участников сверено с GameDiscoverCo и How To Market A Game (расхождение ≤1% для изданий 2024–2026).

Вишлисты Steam не публикует: любые числа вишлистов являются оценками и так помечаются.
