# Лицензия на данные

Производные датасеты, собранные этим проектом (составы фестивалей, нормализованные
метаданные, временные ряды игроков), распространяются по лицензии
**Creative Commons Attribution 4.0 International (CC BY 4.0)**:
https://creativecommons.org/licenses/by/4.0/

Условие — указание источника и ссылка на проект:

> Данные: Steam Observatory (github.com/markshumarov/steam-observatory),
> лицензия CC BY 4.0.

## Что НЕ покрывается этой лицензией

* названия игр, изображения, торговые марки и любые материалы Steam —
  собственность Valve Corporation и соответствующих правообладателей;
* метаданные, полученные от сторонних сервисов, остаются под их условиями
  (см. `docs/data-sources.md`); мы публикуем только агрегаты и ссылки;
* исходные (сырые) дампы страниц в репозиторий не попадают.

## Атрибуция источников

При использовании наших данных просим сохранять ссылки на первоисточники:

* Valve / Steam — публичные страницы и API магазина;
* Internet Archive Wayback Machine — архивные копии страниц Steam;
* GameDiscoverCo и How To Market A Game — контрольные числа участников фестивалей;
* PlayRecon, Output Lag — публичные трекеры фестиваля (сверка, не источник истины);
* Steam Index, Games-Popularity — открытые API по игрокам, отзывам и чартам.
