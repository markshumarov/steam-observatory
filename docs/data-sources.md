# Источники данных: что проверено

Все записи ниже проверены живыми запросами (октябрь 2026). Статус:
**OK** — работает и пригодно; **частично** — работает с оговорками;
**нет** — не работает/недоступно.

## 1. Steam, официальные публичные эндпоинты

| Что | Эндпоинт | Статус | Заметки |
|---|---|---|---|
| Игроков онлайн у приложения | `api.steampowered.com/ISteamUserStats/GetNumberOfCurrentPlayers/v1/?appid=730` | OK | **Без ключа.** Основа метрики «играют в демо» |
| Метаданные игры | `store.steampowered.com/api/appdetails?appids=…&cc=us&l=english` | OK | Жанры, теги, цена, дата релиза. Поля `followers` нет |
| Список всех приложений | `api.steampowered.com/ISteamApps/GetAppList/v2/` | OK | Только appid + название |
| Поиск по магазину (JSON) | `store.steampowered.com/search/results/?json=1&category1=10&tags=492` | частично | Фильтр «демо + тег» работает, но это все демо Steam, не состав фестиваля |
| Отзывы | `store.steampowered.com/appreviews/<appid>?json=1&num_per_page=0` | OK | Общее число отзывов без ключа |
| Страница фестиваля | `store.steampowered.com/sale/nextfest` | частично | 3.1 МБ HTML, но состав подгружается динамически (в HTML ~300 appid) |
| Динамическая выдача распродажи | `store.steampowered.com/saleaction/ajaxgetsaledynamicappquery` | нет | `{"success":8,"err_msg":"Invalid Parameters"}` на всех проверенных наборах параметров (GET и POST) |
| API страницы распродажи | `store.steampowered.com/api/salepage/?id=nextfest` | нет | `{"status":2}` для всех проверенных id |

| Что | Как | Статус | Заметки |
|---|---|---|---|
| Снапшоты страницы фестиваля | `web.archive.org/cdx/search/cdx?url=store.steampowered.com/sale/nextfest` | OK | 1 089 снапшотов с 24.03.2021 |

## Правовые заметки

* Обходим только публичные страницы и публичные API, с вежливым rate limit (~1 запрос/сек)
  и кэшем на диске.
* Не перезаливаем массово ассеты Steam (капсулы/скриншоты) — ссылаемся, а не хостим.
* Все заимствованные числа помечаем ссылкой на источник и методологию.
