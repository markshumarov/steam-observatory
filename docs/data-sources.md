## 6. Найденные ключевые эндпоинты (проверено)

### 6.1 Полный состав фестиваля

```
GET https://store.steampowered.com/actions/ajaxgetdynamicsaleitems
    ?origin=https%3A%2F%2Fstore.steampowered.com
    &max_results=10000&cc=us&tagids_featured=1458863
```

Это ровно тот запрос, который делает сама страница Next Fest. Ответ:

| Поле | Смысл |
|---|---|
| `rgCapsules` | полный список элементов: `{"id": appid, "type": "game"\|"software"}` |
| `nMatchCount` | общее число совпадений (октябрь 2026: 7 322) |
| `bMoreResultsRemaining` | `false` = список полный |
| `rgSolrFacetCounts` | `{tagid: число игр}` — готовая гистограмма по тегам всего фестиваля |

Проверено 25.10.2026: 7 322 элемента, из них 7 304 типа `game`, 421 тег в гистограмме.
**Этот же эндпоинт архивирован в Wayback** (165 снапшотов с 2023 года), что даёт
путь к восстановлению составов прошлых изданий.

### 6.2 CCU демо: нужен appid самого демо

`ISteamUserStats/GetNumberOfCurrentPlayers` для базовой игры нерелизнутой игры
возвращает `{"response":{"result":42}}` (HTTP 404) — статистики нет.
Играть можно только в демо, поэтому CCU надо спрашивать у **appid демо**.

Где взять appid демо:

1. страница игры: `related_items.demo_appid` (JSON внутри HTML) — основной способ;
2. там же ссылка `steam://install/<demo_appid>`;
3. атрибут `data-demoeventstore` на странице фестиваля — но только ~300 записей.

Проверено: `related_items` присутствует у игр с демо, CCU демо отдаётся
(пример: демо DRAGON QUEST MONSTERS — 131 игрок).

### 6.3 Лимиты

* `GetNumberOfCurrentPlayers` режет частоту: 200 запросов подряд при 4 потоках
  дали 429. Рабочий режим — **~1 запрос в секунду** (полный проход 7 304 игр ≈ 2 часа).
* `api/appdetails` **не принимает список appid** — только по одному за запрос.
* Локальный поллер держит `oct2026_demo_ccu.jsonl` открытым, поэтому `git pull --rebase`
  на Windows падает с «unable to unlink». Замеры двух источников (локальный поллер и
  Actions) объединяет `scripts/merge_ccu_sources.py`, а коммит делается без перезаписи
  файла:

  ```
  git fetch origin
  python scripts/merge_ccu_sources.py
  git reset --soft origin/main
  git add -A
  git commit -m "..."
  git push
  ```

  На 26.10.2026 одна ветка дала 63 422 строки, вторая 28 063, объединение — 81 702.
* Проход по всем демо занимает ~130 мин (7 073 × 1.1 с), поэтому поллер обходит
  список от самых недосчитанных appid (`order_ids` в `poll_ccu_loop.py`) — иначе
  короткая смена в CI оставляла бы хвост списка без замеров.
* Страница магазина ~200 КБ; мэппинг демо для 7 304 игр ≈ 1,5 ГБ трафика
  (кэшируется на диске).

## Правовые заметки


* Обходим только публичные страницы и публичные API, с вежливым rate limit (~1 запрос/сек)
  и кэшем на диске.
* Не перезаливаем массово ассеты Steam (капсулы/скриншоты) — ссылаемся, а не хостим.
* Все заимствованные числа помечаем ссылкой на источник и методологию.

## 7. Обогащение: бесплатный каталог Gamalytic

* `GET https://api.gamalytic.com/steam-games/list?page=N` — 200 без ключа, ~133 000
  игр по 100 на страницу, порядок стабилен, фильтра по appid нет (полный обход ≈ 22 мин).
* Поля: `name`, `tags` (до 20 тегов Steam), `genres`, `price`, `copiesSold`,
  `reviewScore`, `unreleased`, `releaseDate`, `developers`, `publishers`.
* `/game/<appid>` отдаёт 403 без платного ключа; вишлистов в бесплатной выдаче нет.
* Каталог качается локально (`scripts/ingest_gamalytic.py`) и в репозиторий не
  кладётся (сторонний снимок ~43 МБ, лицензия Gamalytic); в истории остаются
  только результаты обогащения в `nextfest_games.jsonl`.

## 8. Восстановление составов 2021–2024 по appid

* Страница фестиваля тех лет отдавала в HTML только маппинг
  `{"appid": N, "demo_appid": M}` — 300–330 записей на снапшот, остальное
  подгружалось XHR, которого в Wayback нет.
* `scripts/backfill_ids.py` берёт все снапшоты окна (до 24), объединяет пары
  appid/demo_appid: октябрь 2021 — 59 → 598 записей из 31 снапшота.
* Названия и теги к найденным appid добавляет `scripts/enrich_lineup_ids.py`
  (Gamalytic; остаток — поштучно `appdetails`, пачкой этот эндпоинт не работает).
* Полнота: где есть контроль (июнь и октябрь 2023) покрытие 31–44% — такие
  издания помечаются «≥» и не участвуют в тег-графике.
