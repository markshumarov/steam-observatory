# PlayRecon wishlist gain — расширение для браузера

Добавляет в таблицу фестиваля PlayRecon колонку **«Δ вишлисты»** — оценку того,
сколько вишлистов игра набрала за фестиваль, — и сортировку по этой колонке.

Работает в Vivaldi, Chrome, Edge и любом Chromium-браузере (Manifest V3).

## Установка в Vivaldi

1. Откройте `vivaldi://extensions`.
2. Включите тумблер **Developer mode** (Режим разработчика) справа сверху.
3. Нажмите **Load unpacked** (Загрузить распакованное расширение).
4. Выберите папку `extensions/playrecon-wishlist-gain`.
5. Откройте страницу фестиваля, например
   `https://app.playrecon.com/fests/nextfest/autumn-2026?top=1000&sort=players&dir=desc`.
   Справа от колонки Wishlists появится «Δ вишлисты»; клик по её заголовку
   сортирует таблицу по приросту (повторный клик — в обратную сторону).

## Как считается

В колонке Wishlists страница показывает три вещи: место в топе вишлистов сейчас
(`#75`), прыжок за фестиваль (`▲45`) и оценку вишлистов (`≈733K`).

1. Место до фестиваля = текущее место + прыжок (75 + 45 = 120).
2. По самой таблице строится кривая «место в топе → вишлистов»: для всех игр,
   где известны и место, и оценка (обычно 500+ точек), берётся лог-лог
   интерполяция.
3. Прирост = текущая оценка − оценка на прежнем месте. Для лидера получается
   ≈256 000: на месте #120 было ≈477 000, сейчас ≈733 000.

Наведите курсор на ячейку — во всплывающей подсказке видны все три числа
(место до, оценка до, прирост).

## Ограничения, о которых стоит помнить

* Оценки вишлистов у PlayRecon — модельные, погрешность ±20–30%; это порядок
  величины, а не точное число.
* Места в топе относительные: пока одни игры растут, другие смещаются вниз,
  поэтому «прыжок» — не абсолютный прирост.
* Кривая «место → вишлисты» взята из текущего снимка таблицы.
* Если у игры нет прыжка в топе (только `#N≈K`), прирост посчитать нельзя —
  в ячейке стоит «—».
* Сортировка выполняется в браузере (перестановкой строк). Если страница
  перерисует таблицу сама (например, при смене сортировки на её стороне),
  порядок сбросится, а колонка останется.

## Проверка

Логика и вставка в DOM проверены на сохранённом снимке страницы:
`python scripts/test_extension.py` — 6 проверок (колонка, 1011 ячеек, значение
лидера +256K, подсказка, сортировка вверх и вниз), 0 ошибок в консоли.
